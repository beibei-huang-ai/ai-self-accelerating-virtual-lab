# AI Self-Accelerating Virtual Lab

## Live Application

**[Launch the Virtual Lab](https://ai-self-accelerating-hackathon.vercel.app/)**

## Project Overview

An interactive AI-powered virtual laboratory that uses multiple specialized AI agents to evaluate experimental evidence, challenge competing hypotheses, and recommend subsequent experiments.

## Scientific Agent Architecture

The platform is designed around four specialist roles:

1. **Affinity Scientist:** Evaluates candidates for binding potential.
2. **Developability Scientist:** Assesses manufacturability and development considerations.
3. **Scientific Skeptic:** Challenges assumptions and searches for evidence that could falsify competing hypotheses.
4. **Decision Specialist:** Evaluates the specialists' arguments and recommends the next experimental step.

- Support evidence-based experimental planning.
- Demonstrate an AI-assisted virtual laboratory workflow.
